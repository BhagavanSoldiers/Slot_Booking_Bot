SAVEETHA BOOKING ASSISTANT - SINGLE WINDOW

FIRST TIME:
1. Make sure Python 3.11+ is installed.
2. Double-click "Start Saveetha Agent.bat".
3. Wait for the first-time setup to install PySide6, Playwright and Chromium.
4. The application opens as ONE window with:
   - booking controls on the left
   - Saveetha learner portal on the right

EVERY LATER TIME:
1. Double-click "Start Saveetha Agent.bat".
2. The existing environment is reused.
3. No token needs to be copied for the embedded UI.

The Playwright browser runs in the background. The visible learner portal is embedded in the same desktop window.
Do not put your Saveetha password in this folder or upload it to GitHub.
